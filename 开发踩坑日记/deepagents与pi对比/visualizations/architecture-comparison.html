Architecture Comparison

Pi 5层分层架构 vs DeepAgents 图编排 + Middleware 堆栈架构

Pi
TypeScript / Bun
L1 — User Interface
prompt() / steer() / followUp() / continue()
▾
用户交互入口。steer() 可在 assistant turn 完成后注入指令。
followUp() 在 Agent 即将停止时触发新一轮对话。
▼
L2 — Agent (有状态包装器)
AgentState 管理 + 队列编排 + 事件分发
▾
持有完整状态: systemPrompt, model, tools, messages, pendingToolCalls。
管理 steeringQueue, followUpQueue, pendingMessageQueue。
processEvents() 更新状态并通知监听器。
▼
L3 — AgentLoop (无状态循环)
纯函数: 执行 LLM 调用 → 工具调度 → 事件发射
▾
runAgentLoop(prompts, context, config, emit, signal)
核心流程: getSteering → inject messages → streamAssistant → executeTools → checkStop
无状态设计使得测试和复用极为简单。
▼
L4 — LLM Stream
模型通信 + 流式响应 + 消息转换
▾
transformContext → convertToLlm → build context → getApiKey → streamSimple
流式事件: start → text_delta/thinking_delta/toolcall_delta → done/error
多 Provider 通过 lazy registration 统一。
▼
L5 — Tool Execution
副作用发生地: prepare → execute → finalize
▾
支持 sequential / parallel 执行模式。
beforeToolCall / afterToolCall 钩子可拦截任意阶段。
返回 AgentToolResult { content, details, terminate? }。
DeepAgents
Python / uv
User Input
agent.invoke({messages: [...]})
▾
通过 CompiledStateGraph.invoke() 启动。
支持 streaming、async、batch 模式。
CLI 提供交互式 TUI (Textual)。
▼
State: _DeepAgentState
DeltaChannel 优化 + AgentState 继承
▾
messages 使用 DeltaChannel 将 checkpoint 增长从 O(N²) 降到 O(N)。
继承 LangGraph 的 State 管理，支持 checkpointer 持久化。
snapshot_frequency=50 控制快照频率。
▼
Middleware Stack
Base → User → Tail 三层堆栈
▾
Base: TodoList + Skills + Filesystem + SubAgent + AsyncSubAgent + Summarization + PatchToolCalls
User: 自定义 middleware 插入位置
Tail: Profile extra + ToolExclusion + PromptCaching + Memory + HITL
▼
LangGraph Runtime
CompiledStateGraph 执行引擎
▾
create_agent() 返回 CompiledStateGraph。
节点: agent (LLM call) → tools (工具路由) → 循环
recursion_limit=9999 防止无限循环。
支持 LangGraph Studio 可视化调试。
▼
Backend / Tools
BackendProtocol + 内置工具集
▾
Backend: StateBackend (默认) / FilesystemBackend / 自定义
Tools: write_todos, ls, read_file, write_file, edit_file, glob, grep, execute, task
权限: FilesystemPermission 访问控制规则

架构差异要点

调用链

Pi: Agent.prompt() → AgentLoop.run() → streamSimple() → executeTools() → emit()

调用链

DeepAgents: graph.invoke() → Middleware Stack → LLM → ToolNode → 循环

状态管理

Pi: 显式 mutable AgentState (getter/setter)
DeepAgents: LangGraph DeltaChannel (O(N) checkpoint)

流式处理

Pi: EventStream push-based (text_delta 级别)
DeepAgents: LangGraph streaming pull-based

扩展方式

Pi: 事件订阅 (pi.on) + 注册式 API
DeepAgents: Middleware 插入 + Profile 覆盖

测试策略

Pi: AgentLoop 纯函数易于单元测试
DeepAgents: 依赖 LangGraph runtime 集成测试
