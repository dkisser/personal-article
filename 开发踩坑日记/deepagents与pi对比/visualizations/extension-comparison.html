Extension Mechanism

Pi 事件驱动扩展 vs DeepAgents Middleware 堆栈扩展

Pi 扩展哲学

"事件驱动 + 注册式 API + 可拦截的生命周期钩子"
扩展不是继承或修改核心代码，而是通过事件订阅和行为注入来扩展能力

DeepAgents 扩展哲学

"Middleware 插入 + Profile 覆盖 + 协议实现"
扩展通过插入 Middleware 到堆栈、注册 Profile 调优行为、实现协议接口来扩展能力

关键差异总结

扩展粒度

Pi 提供事件级别细粒度控制 (text_delta 级别)
DeepAgents 提供请求/响应级别控制

拦截能力

Pi 任意事件可 cancel 或替换逻辑
DeepAgents Middleware 可修改但无法 cancel 已发出请求

组合方式

Pi 多扩展通过事件监听器叠加
DeepAgents Middleware 通过堆栈顺序组合

开发体验

Pi 需要理解事件系统和 TypeBox
DeepAgents 需要理解 LangChain 生态和 Pydantic
