## 「K2.7 Code 高速版，yyds」 · 墨问

**「K2.7 Code 高速版，yyds」**

上周查看 Kimi 的时候无意间看到抢先体验计划。

“这什么玩意儿？”

抱着好奇的心态，申请了这个计划。大概过了一小时就通过了，审核效率还挺快。

![](images/k2-7-code-gao-su-ban-yyds/image-1.png)

开通之后，仔细一看其实也没啥，就是一个高速版。

“这不是 MiniMax 的玩法吗？HighSpeed 速度翻倍，订阅价格也翻倍”

但咱开都开了，就试试看呗。我让它把我 Browser-Bridge 项目的安装过程调整成纯二进制安装，不再依赖 bun和git。

总共跑了将近俩小时，然后直接给我把5小时的额度干没了。

![](images/k2-7-code-gao-su-ban-yyds/image-1.jpg)

但速度是真快，我平时应该是 120~200 左右，这个高速版真的差不多是6倍速。而且是在 Coding Plan 里面的，不像 MiniMax 强制绑定一个新的套餐，点赞~~
