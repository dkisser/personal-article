# Personal Article Vault

这是一个基于 Obsidian 的**个人文章管理仓库**，用于管理从灵感记录到多渠道发布的完整写作工作流。

## 各组件的职责与关联

### 1. 分类目录（内容层）

六（七）个主题文件夹存放实际的文章内容。每篇文章是一个 Markdown 文件，使用 YAML frontmatter 记录元数据：

| 字段 | 说明 |
|------|------|
| `status` | `idea` / `draft` / `published` |
| `tags` | 主题标签 |
| `created` | 创建日期 `YYYY-MM-DD` |
| `published` | 发布日期（发布时填写） |
| `category` | 所属分类目录名 |
| `source` | 原文链接（通常为墨问） |
| `channels` | 各渠道发布数据（数组） |
| `description` | 文章摘要（用于 catalog 与 wiki） |

文章之间使用 Obsidian wiki-link（`[[文章标题]]`）建立知识关联。

### 2. manager/ 目录（管理层）

与分类目录一一对应，每个 `.md` 文件是该分类的**状态看板**：

- **文章列表表格**：汇总标题、状态、标签、创建/发布日期
- **按状态筛选**：`### 想法` / `### 草稿` / `### 已发布` 三个区块
- **描述摘要**：已发布文章附带一句话简介

**manager/README.md** 是全库导航中心，包含分类汇总表（想法/草稿/已发布/总计数量）和快速入口。

### 3. wiki.md（公开索引层）

只收录 `status: published` 的文章，按分类整理。它是一个**单向索引**：wiki 链接到文章，文章本身不反向引用 wiki。用于对外分享或快速浏览已发布内容。

### 4. 渠道反馈看板

追踪每篇文章在各渠道（墨问、知乎、CSDN、infoQ 等）的投放效果。数据来源于文章 frontmatter 中的 `channels` 数组，支持手动汇总或 Dataview 自动生成。

### 5. templates/（模板层）

新文章的起点。复制 `文章模板.md` 到目标分类目录，填入内容即可。模板包含标准 frontmatter 和文章结构（背景 → 正文 → 总结 → 相关链接）。

### 6. goals.md & reward.md（激励层）

个人写作目标与奖励机制，配合定期回顾使用。

## 工作流概览

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   灵感闪现   │ --> │  新建文章   │ --> │  写作中     │
│  (任意目录)  │     │ (复制模板)  │     │  status:    │
└─────────────┘     └─────────────┘     │   draft     │
                                        └──────┬──────┘
                                               │
                                               v
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  渠道反馈看板 │ <-- │  正式发布   │ <-- │  完成写作   │
│  (数据追踪)   │     │  (更新      │     │  status:    │
└─────────────┘     │  frontmatter)│     │  published  │
                    └─────────────┘     └──────┬──────┘
                                               │
                    ┌─────────────┐            │
                    │   wiki.md   │ <----------┘
                    │ (公开索引)  │
                    └─────────────┘
```

1. **新建**：从 `templates/文章模板.md` 复制到目标分类目录，填写 frontmatter
2. **写作**：在分类目录中编辑文章内容，使用 wiki-link 关联已有笔记
3. **发布**：更新文章 frontmatter（`status: published`、`published: YYYY-MM-DD`、添加 `description` 和 `channels`）
4. **同步 catalog**：在 `manager/<分类>.md` 中登记文章，更新 `manager/README.md` 统计数字
5. **更新 wiki**：在 `wiki.md` 对应分类下添加单向链接
6. **追踪数据**：在文章 frontmatter 的 `channels` 中录入各渠道表现，同步到 `manager/渠道反馈看板.md`
