### 已发布

- [[记事本/CSDN真是个神奇的网站\|CSDN真是个神奇的网站]] — 作者惊喜发现 CSDN 带来第一个 browser-bridge 用户，且对方直接私聊询问使用方式。作者曾因 CSDN 注水文章、VIP 限制而弃用，如今为做自媒体重新发帖。此事也提醒作者：安装难易度很影响推广效果。
- [[记事本/ego-lite 初体验\|ego-lite 初体验]] — 作者体验 ego-lite：logo 简约高颜值，Space 设计将 Agent 与人的操作区域分开、契合注意力稀缺场景，Accessibility Tree 借 Chrome 内核简化页面结构。启发：信息提取应先取骨架再逐节点放大。
- [[记事本/Tabbit和ego-lite\|Tabbit和ego-lite]] — 作者对比 Tabbit 与 ego-lite：前者想在一个浏览器内直接完成任务（整理邮件、订机票、抓信息），后者追求简约，只把工具暴露给其它 Agent。二者本质相同，差异在于产品理念和视图管理方式，ego-lite 颜值更高。
- [[记事本/iTerm 2 真好用\|iTerm 2 真好用]] — 作者换上 iTerm 2 后发现许多功能原生终端需折腾半天才实现。分屏只需 cmd+d，无需 tmux；还能通过 Mac 通知栏主动提醒任务完成，避免盯屏。作者感到省下注意力让人更开心。
- [[记事本/MonoRepo中使用不同编程语言的设想\|MonoRepo中使用不同编程语言的设想]] — 作者在为 browser-bridge 设计控制面板时，想起 pinchTab 仅 28MB 且零依赖的安装体验，希望实现同样小巧便捷的方案。他推测 Go/Rust 编写的 HTTP 服务器体积极小，可直接托管 JS 前端，因此整体很小。项目目前用 MonoRepo 统一 Node.js 生态，共享协议层能在编译期发现契约变更，效率高。但作者不熟悉 Go/Rust，担心出问题难以排查，且多语言会让共享协议层失效。最终问题变成：跨语言 MonoRepo 如何方便开发。作者此前只用过 Java+JS，现在最喜欢 Node+JS，考虑尝试 Go。
