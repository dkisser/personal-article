## 渠道字段模板

每篇文章的 frontmatter 中嵌入 `channels` 数组。以下是可复制模板：

```yaml
channels:
  - name:          # 渠道名称，必填
    url:           # 文章在该渠道的链接
    views:         # 曝光 / 阅读数
    likes:         # 点赞数
    collects:      # 收藏数
    shares:        # 转发 / 分享数
    comments:      # 评论数（可选）
    published_at:  # 在该渠道的发布日期，格式 YYYY-MM-DD
```

### 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|:--:|------|
| `name` | string | 是 | 渠道名称，如「微信公众号」「知乎」「掘金」 |
| `url` | string | 否 | 文章在该渠道的永久链接 |
| `views` | number | 否 | 曝光量或阅读量 |
| `likes` | number | 否 | 点赞数 |
| `collects` | number | 否 | 收藏数 |
| `shares` | number | 否 | 转发或分享数 |
| `comments` | number | 否 | 评论数（部分渠道支持） |
| `published_at` | string | 否 | 在该渠道的发布日期，格式 `YYYY-MM-DD` |

### 完整示例

```yaml
channels:
  - name: 微信公众号
    url: https://mp.weixin.qq.com/...
    views: 1200
    likes: 45
    collects: 12
    shares: 8
    comments: 3
    published_at: 2026-05-11
  - name: 知乎
    url: https://zhuanlan.zhihu.com/...
    views: 800
    likes: 30
    collects: 20
    shares: 5
    published_at: 2026-05-11
```
